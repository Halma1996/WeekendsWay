# WeekendsWay — первый этап доработки

- Маршруты теперь открываются через Google Maps universal URL, сохраняя режим walking/driving/transit/bicycling (в отличие от прежнего `google.navigation:`).
- JSON сохраняется атомарно через `QSaveFile`, чтобы не терять данные при прерывании записи.
- Поля ввода адресов адаптированы к ширине экрана.
- Добавлены сообщения при невозможности открыть карты и при ошибке сохранения.
- Убрана временная отладочная надпись с главного экрана.

## Сборка
Нужны Qt 6.8.3 для Android arm64-v8a, Android SDK Platform 35, NDK, JDK 17 или новее, CMake и Ninja. Откройте CMakeLists.txt в Qt Creator, выберите Android arm64-v8a kit, Build > Build APK.

Для проверки актуального проекта подготовлен workflow GitHub Actions в ветке `Ai_brench`.

## Контакты: дополнительные сведения
- У контактов появились необязательные поля: домофон, этаж, квартира.
- Сведения отображаются в списке и доступны при редактировании.
- Старый friends.json загружается без потери данных.

## Быстрое копирование домофона
- В карточке контакта рядом с ключом домофона добавлена кнопка копирования.
- В буфер обмена копируется только значение ключа, без подписи.
- Показывается уведомление об успехе или ошибке; кнопка скрыта при пустом ключе.

## Раскрывающиеся карточки друзей
- Список показывает только имя, адрес и кнопку маршрута.
- Кнопка со стрелкой раскрывает домофон, этаж, квартиру и действия редактирования/удаления.
- Копирование домофона доступно в раскрытой карточке.
- Сохранение данных и совместимость со старыми записями не изменены.

## APK через GitHub Actions
- Актуальные файлы из архива подготовлены для загрузки в ветку `Ai_brench`.
- Автоматическая сборка запускается при push в `Ai_brench`.
- Исправлена установка Qt 6.8.3 для Android: используется host `all_os` с инструментами Linux.
- Используются Android API 35, Build Tools 35.0.0, NDK 26.1.10909125 и JDK 17.
- Собирается устанавливаемый Debug APK для arm64-v8a; перед загрузкой проверяется подпись.
- В README добавлены шаги скачивания APK из Artifacts. Ветка `master` не изменяется.
